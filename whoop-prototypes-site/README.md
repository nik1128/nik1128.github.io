# WHOOP support prototypes

Two prototypes by Nikhil Parmanand Sakhare, built to test my thinking about Membership Services systems.

- **[One member, two systems](two-systems/)**: the same case in Salesforce Service Cloud and a WHOOP member platform, with a shared member ID, role-based access, channel-based identity checks and a CTI call bar.
- **[AI support agent with guardrails](agent/)**: an in-app agent that hands anything involving money or health to a person, enforced in code. Details in [agent/README-agent.md](agent/README-agent.md).

Both run in the browser with no install, no build step and no API key.

> Built from public information. Fictional data. Not affiliated with or endorsed by WHOOP.
